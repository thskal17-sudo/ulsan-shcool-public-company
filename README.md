# 울산 공공기관 강사 구인공고 알리미

울산 지역 공공기관(교육청·학교, 시설공단 체육시설, 국가·공공기관 등)의 강사 구인공고를 매일 아침 모아
**강사잇다 공고 올리기 양식(엑셀)으로 정리해 이메일로 보내주는** 프로젝트입니다. GitHub Actions 에서 무료로 돌아갑니다.

- 설계 문서: [docs/DESIGN.md](docs/DESIGN.md)
- 수집 대상 목록: [config/sources.yaml](config/sources.yaml)
- 강사 공고 판별·분류 규칙: [config/keywords.yaml](config/keywords.yaml)

## 받게 되는 것

매일 새벽(01:37 KST, 통째로 빠지는 날에 대비한 예비 실행 04:37)에 수집해 아침 전에 이런 메일이 옵니다.
GitHub 예약 실행은 몇 시간씩 밀리곤 해서(2~4시간 관측) 새벽으로 잡았습니다.

- 제목: `[울산 강사구인] 9/27(일) 신규 12건 · 마감임박 5건`
- 본문: 신규 공고 표(마감 D-day, 분야, 기관, 제목 링크), 수집 상태 안내
  - 빨간 상자 **확인이 필요한 사이트**: 사이트 개편 등으로 공고를 놓쳤을 수 있는 곳
  - 회색 상자 **접속 안 된 사이트**: 수집 서버(해외)의 접속을 막거나 일시 장애인 곳. 따로 할 일 없음
- 접속 안 된 사이트가 있으면 몇 분 뒤 다른 수집 서버에서 그 사이트만 다시 읽고,
  새 공고가 나오면 **보충 메일**(`[울산 강사구인] 9/27(일) 보충 신규 2건`)이 한 통 더 옵니다.
- 예비 실행(04:37)은 그날 메일을 이미 보냈으면 그 뒤 새로 올라온 공고가 있을 때만 보충 메일을 보내고,
  없으면 보내지 않습니다. 새벽 실행이 빠졌거나 메일을 못 보냈으면 예비 실행이 전체 메일을 보냅니다.
- 첨부: `강사잇다_울산_2026-09-27.xlsx` — 강사잇다 **공고 올리기 양식** 그대로 ([config/gangsaitda_template.xlsx](config/gangsaitda_template.xlsx))
  - '공고' 시트에 **마감 전 공고 전부**가 한 줄씩 (마감 빠른 순)
  - 제목(연도·날짜는 뺌), 기관명, 지역(울산 + 구·군), 마감일, 원문 링크
  - 수업 일정·수업 대상·모집 인원·지원 자격·제출 서류·지원 이메일은 공고 본문과 첨부 공고문(HWP/PDF)에서 찾아 채움.
    수업 일정을 못 찾으면 '원문 공고 참고', 상세 내용은 원문 제목·분야·접수 마감·원문 링크로 씀
  - 마감일을 못 찾은 공고는 **'처리' 칸에 '보류'** → 강사잇다가 그 줄을 올리지 않음. 원문에서 마감일을 확인해 적고 '보류'를 지우면 됨
  - '메모' 칸: 수집한 게시판과 확인할 점 (강사잇다는 무시)
  - 신규·마감임박·수집현황까지 담은 기존 보고서(`울산_강사구인_…xlsx`)는 메일에 붙이지 않고 Actions 실행 기록(Artifacts)에만 30일 보관

## 캠프·교육 수주 공고 (나라장터·S2B)

강사 공고와 별도로, 두 곳에서 진로·취업·창업 캠프와 교육 운영 공고를 매일 새벽(02:23, 예비 05:23 KST)과
낮(13:17 KST)에 모아 **새 공고가 있을 때만** 메일을 한 통 보냅니다 (`.github/workflows/camp.yml`).

- **나라장터 용역 입찰공고** (조달청 API): 대학·공공기관·교육청의 큰 입찰이 주로 여기
- **S2B 학교장터 견적요청·소액수의 공고** (교육청 홈페이지용 공개 목록, 부산·울산·경남 학교): 학교가 2천만원 이하로
  사는 캠프·교육은 대부분 여기. 공고마다 상세 화면에서 '견적을 낼 수 있는 업체' 범위를 확인
  - 전체공개 / 부산 업체 가능 → 바로지원
  - 학교가 업체를 미리 정해 둔 견적(공급업체 선택) → 참고 (영업 대상 학교로 활용). 1인 수의 견적은 대부분 이 경우
- 분야: 공고명에 진로·취업·창업 등이 있으면 **진로·취업·창업**, 그 밖에 '교육'이 있으면 **[교육]** 으로 표시
  ('캠프'는 직업·진학·꿈·미래·리더십 같은 말과 함께 있을 때만, '교육청'·'교육센터' 같은 이름 속 '교육'은 제외)
- 제목: `[캠프·교육 수주] 9/30(수) 바로지원 2건 · 검토 1건 · 참고 4건`
- **★ 바로지원**: 참가 가능 지역이 부산(또는 제한 없음)이고, 수의계약·S2B 견적이거나 추정가격 2,000만원 이하
- **검토**: 참가 가능 지역이지만 금액이 큰 입찰, 또는 참가 범위를 읽지 못한 공고
- **참고**: 다른 지역 업체나 학교가 정한 업체만 낼 수 있음 — 과업 내용과 금액을 견적 기준으로, 학교는 영업 대상으로 참고
- 이미 알린 바로지원·검토 공고가 마감 3일 이내로 남으면 '마감임박'에 다시 보여줌
- 키워드·지역·금액·S2B 지역 기준: [config/camp.yaml](config/camp.yaml)
- 필요한 Secret: `G2B_API_KEY` (공공데이터포털 '조달청_나라장터 입찰공고정보서비스' 일반 인증키). S2B 는 키 없음
- 한 곳이 막혀도 다른 곳 공고는 알리고, 메일 아래에 읽지 못한 곳을 표시
- 시험 실행: **Actions → 캠프·교육 수주 공고 (나라장터·S2B) → Run workflow** (메일 끄고 실행하면 결과는 실행 기록 요약에만 표시)

## 설정 방법 (처음 한 번)

### 1. Gmail 앱 비밀번호 만들기

1. 보내는 데 쓸 Google 계정에 [2단계 인증](https://myaccount.google.com/signinoptions/two-step-verification)을 켭니다.
2. [앱 비밀번호](https://myaccount.google.com/apppasswords)에서 새 앱 비밀번호(16자리)를 만듭니다.

### 2. GitHub Secrets 등록

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서 등록합니다.

| 이름 | 값 | 필수 |
|---|---|---|
| `SMTP_USER` | 보내는 Gmail 주소 | ✅ |
| `SMTP_APP_PASSWORD` | 위에서 만든 앱 비밀번호 16자리 | ✅ |
| `MAIL_TO` | 받는 주소 (여러 명이면 쉼표로 구분). 비우면 `SMTP_USER` 로 보냄 | |
| `WORK24_API_KEY` | [고용24 Open API](https://www.work24.go.kr/cm/e/a/0110/selectOpenApiIntro.do) 채용정보 인증키 | |

`WORK24_API_KEY` 가 없으면 고용24만 건너뛰고 나머지는 정상 수집합니다 (수집현황에 '설정필요'로 표시).

### 3. 시험 실행

**Actions → 매일 강사 공고 수집·메일 발송 → Run workflow** 를 누르면 바로 한 번 실행됩니다.
메일이 오면 설정 완료이고, 이후 매일 자동으로 실행됩니다.

- 첫 메일에는 최근 45일 안에 올라온, 마감 전 공고가 모두 신규로 들어갑니다.
- 실행이 실패하면 GitHub 가 저장소 주인에게 실패 알림 메일을 보냅니다.

## 동작 방식

```
sources.yaml 의 게시판·API ──▶ 수집 ──▶ 강사 공고 판별·분야 분류 ──▶ DB(신규 판정)
                                                                    │
       메일(강사잇다 양식 첨부) ◀── 공고문에서 수업 일정 등 찾기 ◀──┘
```

- 수집 기록(SQLite)은 저장소의 `state` 브랜치에 저장됩니다. 지우면 다음 실행 때 모든 공고가 다시 신규로 옵니다.
- 메일 발송에 실패한 날의 공고는 다음 날 다시 신규로 보내집니다.
- 한 사이트가 고장 나도 나머지는 계속 수집하고, 실패한 사이트는 끝에서 한 번 더 시도합니다. 그래도 안 되면 메일 상단에 표시됩니다.
- 구·군청·시청 등 일부 사이트는 GitHub 가 배정하는 수집 서버의 지역에 따라 접속이 막힙니다 (같은 시각에도 서버에 따라 됐다 안 됐다 함).
  그래서 접속 안 된 사이트는 같은 실행 안에서 새 서버를 받아 한 번 더 수집합니다 (`catch-up` 작업).

## 규칙 바꾸기

- **강사 공고로 볼 단어·뺄 단어**: `config/keywords.yaml` 의 `include` / `exclude` / `result_notice`
- **합격자 발표 같은 결과공고도 받기**: `keep_result_notices: true`
- **분야 분류**: `config/keywords.yaml` 의 `categories` (위에서부터 먼저 맞는 분야, `!단어` 가 있으면 그 분야는 건너뜀)
- **게시판 추가**: `config/sources.yaml` 에 항목 추가. 구조를 모르면
  **Actions → 사이트 진단 (probe) → Run workflow** 에서 `--no-reach --url <목록 주소>` 로 먼저 확인합니다.

## 직접 실행 (개발용)

```bash
pip install -r requirements-dev.txt
python -m pytest                                            # 테스트
PYTHONPATH=src python -m ulsan_jobs check-source uic_lesson  # 게시판 하나 시험 수집
PYTHONPATH=src python -m ulsan_jobs run --no-mail           # 전체 수집, 엑셀만 out/ 에 생성
PYTHONPATH=src python -m ulsan_jobs send-test-mail          # 메일 설정 확인 (SMTP_* 환경변수 필요)
```
